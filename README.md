# Nguyen Hoang Nguyen: 3D reconstruction portfolio

Static site (no build step) for GitHub Pages.

- `index.html`, `assets/`: portfolio page
- `viewer/`: SuperSplat Viewer 1.37.0 (MIT) + `scene.compressed.ply` (Hải Triều street, model E29p1n) + `settings.json` (start camera)

Local preview: `python3 -m http.server 8000`, then open http://localhost:8000
